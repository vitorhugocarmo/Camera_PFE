
# Camera PFE — Capturador de Imagens

## Descrição
O Camera PFE é uma aplicação web desenvolvida para a atividade
intermediária de Programação Front-End. O sistema permite acessar
a câmera do dispositivo, capturar fotografias, aplicar filtros
visuais e inserir informações diretamente na imagem.

## Funcionalidades
- Acesso à câmera com solicitação de permissão.
- Exibição do vídeo em tempo real.
- Captura de fotografias.
- Filtros original, preto e branco, sépia e invertido.
- Identificação da fotografia com o nome do aluno.
- Registro da data e hora da captura.
- Visualização e download da imagem processada.
- Botões para ligar e desligar a câmera.
- Tratamento de erros de acesso à câmera.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- MediaDevices e getUserMedia
- Canvas API
- Eventos JavaScript e manipulação do DOM

## Como executar
1. Abra a pasta do projeto no Visual Studio Code.
2. Execute o arquivo index.html utilizando o Live Server.
3. Permita o acesso à câmera quando solicitado.
4. Digite o nome do aluno e escolha um filtro.
5. Clique em Capturar foto.
6. Baixe a fotografia processada, se desejar.

O acesso à câmera exige um contexto seguro, como localhost
ou uma página publicada com HTTPS.

## Objetivo
Aplicar os conhecimentos de acesso à câmera, captura de imagens,
processamento com Canvas e controle adequado dos recursos
do dispositivo.
